This file containt simple instructions on the intent of the program.
The program is an RPG, input based game. One is required to read programs output in the terminal and provide a corresponding input.
Question -> Answer relaptionship.

When begin_rpg() function is run within the main function, one has to either:
Make a character, once more, by following the output/input relationship OR
Use a generated character that the program offers.

Once this step is complete, the program has a main scenarion, which is referred to Begin Story. It has 3 steps.
ALternatively, one has the option of infinite fighthing, however, it is loop based. Values for health can be hardcoded, for certain scenarios.

In the story version, depending on your input, certain actions can be done, of ocurse, they are input based with respect to 
what is shown in the terminal. ALl of those steps are designed to have a playable game so that you reach the final destination, and perhaps,
one day, defeat the greatest King of Heroes.
